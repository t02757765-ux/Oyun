# 🎮 Oyun Adı

Oyunun ana ekranından veya oynanışından bir **ekran görüntüsü** ya da **GIF** buraya eklenir.

## 📝 Hakkında
Bu proje, **Pygame** kütüphanesi kullanılarak geliştirilmiş 2 boyutlu klasik bir arcade tarzı hayatta kalma oyunudur. Amaç, gelen meteorlardan kaçarak en yüksek skora ulaşmaktır.

**Nasıl oynanılır?**:
windows ise .exe dosyasını indirip çalıştırınız.
Linux ise .elf i indirin.
Android için .apk indirin.


## 🛠️ Kullanılan Teknolojiler
* **Python 3.x**
* **Pygame**

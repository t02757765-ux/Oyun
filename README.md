# 🎮 Oyun Adı (Örn: Uzay Macerası)

Oyunun ana ekranından veya oynanışından bir **ekran görüntüsü** ya da **GIF** buraya eklenir.

## 📝 Hakkında
Bu proje, **Pygame** kütüphanesi kullanılarak geliştirilmiş 2 boyutlu klasik bir arcade tarzı hayatta kalma oyunudur. Amaç, gelen meteorlardan kaçarak en yüksek skora ulaşmaktır.

## 🕹️ Kontroller
* **Yön Tuşları / WASD**: Karakteri hareket ettirir.
* **Boşluk Tuşu (Space)**: Ateş eder / Zıplar.
* **ESC**: Oyunu durdurur.

## ⚙️ Kurulum ve Çalıştırma

1. Bilgisayarınızda Python yüklü olmalıdır.
2. Projeyi klonlayın veya indirin:
   ```bash
   git clone https://github.com/t02757765-ux/Oyun
   ```
3. Klasöre gidin:
   ```bash
   cd oyun-adi
   ```
4. Gerekli kütüphaneyi yükleyin:
   ```bash
   pip install pygame
   ```
5. Oyunu başlatın:
   ```bash
   python main.py
   ```

## 🛠️ Kullanılan Teknolojiler
* **Python 3.x**
* **Pygame**
